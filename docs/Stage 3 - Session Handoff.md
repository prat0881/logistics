## Conventions & key learnings (reuse in Plan 7+)
- **Flow:** brainstorm → write plan (`superpowers:writing-plans`) → subagent-driven execution (`superpowers:subagent-driven-development` — fresh implementer per task, TDD, per-task spec+quality review, **opus** whole-branch review) → finish via PR → **verify in prod**. New branch per plan (`feat/plan-N-<name>` off `main`); plan doc + implementation ship as one PR. Ledger `.superpowers/sdd/progress.md` (gitignored — fresh each plan). Models: **sonnet** implementers + task reviewers; **opus** final review + design-heavy tasks. **Proof it works:** the Plan-6 opus whole-branch review caught a Critical (non-admin Step-1 403) + Important (Step-2 double-PATCH) that per-task reviews + green tests missed.
- **Extensibility Core golden rules (enforced by real code):** never hand-write a status — go through `StatusService.fire` or `QueryStatusProjector.recompute`; never raw-write a user-editable field — route through `ChangeMediator.apply(req, uow)` (declare its impact class). Type each impact map `Record<keyof …Input | "@create" | "@delete", ImpactClass>` for compile-time completeness.
- **Owned status columns** (`Leg.status`): authoritative column written in the same tx as the `StatusTransition` log via `DispatchingStateStore`. Tests create real `Query`+`Leg` fixtures (a synthetic id → P2023/P2025).
- **Derived-on-read:** `Query.freightMode`/origin/destination + per-leg roll-ups computed in `shapeQuery` (never stored). The isomorphic `validateRoute` is the single §10 source — the browser runs it too.
- **Soft user refs:** `assignedUserId`/`uploadedById`/`actorId` are plain nullable `@db.Uuid`, no relation. e2e tests use a **UUID jwt `sub`**.
- **Validation:** bind Zod at param level. `PrismaExceptionFilter`; **P2003 (FK) NOT mapped** → verify referenced ids in the service.
- **Shared enums:** `const` object + union + `Object.values(...) as [X,...X[]]` array pinned by a `toEqual` test. Never a TS `enum`.
- **`cookie-parser` import:** e2e specs use the **default import** (namespace import throws under `esModuleInterop`).
- **API CI gotcha:** CI runs a **fresh migrated-but-UNSEEDED** Postgres → every test **seed-independent + self-cleaning** (own reference data + own rows by a unique prefix; a query delete cascades). Verify vs `prisma migrate reset --force --skip-seed` + `pnpm run ci` before pushing.
- **⚠ Frontend conventions (Plan 6 — reuse for any Plan-7 UI):**
  - **HTTP:** `fetchJson`/`postJson`/`patchJson`/`del` from `@/lib/api` (cookie auth; `ApiError` parses 422 `{findings}` + 400 `{issues}`; guards 204/empty).
  - **Server cache:** TanStack Query keyed `["<feature>", params]` / `["<feature>", id]`; mutations invalidate `["query", id]` and rely on the **re-GET** (`shapeQuery` graph) for derived fields/rollups/`assignedCargoIds` — never trust write responses for those.
  - **Forms:** RHF + `zodResolver(@svyft/shared schema)` + shadcn `Form*` (`FormItem`/`FormLabel` **throw** outside `<FormField>` — use plain `div/label` for non-fields). Datetime fields use the floating-wall-clock `toIsoOffset`/`isoToLocalInput` pair (TZ-independent, digit-stable).
  - **Findings** render through ONE `<FindingsPanel>` (deduped via `dedupeFindings`); draft warns, create blocks.
  - **⚠ Web CI:** run `pnpm --filter @svyft/web typecheck` (or `pnpm run ci`) — **`vite build`/esbuild SKIPS type errors** (this hid a real typecheck failure in Plan 6).
  - **Web tests:** Vitest + `renderWithProviders` (`@/test/renderWithProviders`) + `mockFetch` (`@/test/mock-fetch`); stub `/api/auth/me` + endpoints; `afterEach(vi.unstubAllGlobals())`. Radix Select is **jsdom-flaky** → drive the hidden native `<select>` / assert values another way; `test/setup.ts` has ResizeObserver + pointer-capture + scrollIntoView no-op polyfills. Use valid UUIDs for `.uuid()` fields.
  - **Dev server:** `vite.config` aliases `@svyft/shared` → its TS source (else the CJS build breaks the native-ESM dev server). `.claude/launch.json` (gitignored) has a `web` preview config for the Claude_Preview tools.
- **Ops lesson (PR #10):** use `docker compose exec api …` for one-off prod tasks (not `run`). Probe live routes by their real path — 401 = route exists + guarded; 404 = route absent (e.g. `/api/queries` was 404 pre-Plan-6, now 401).
